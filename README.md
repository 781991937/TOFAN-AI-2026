# TOFAN AI 2026 — أكاديمية طوفان الذكية

المشروع هو **تطبيق ومنصة أكاديمية** وليس Telegram Bot. الواجهة الحالية هي Web App/PWA، والـBackend مستقل ومبني بـ FastAPI. Telegram يمكن الاحتفاظ به لاحقًا كقناة اختيارية فقط.

## البنية الحالية

- Web App/PWA في `web/`.
- FastAPI API في `app/api/`.
- المصادقة والجلسات وPasskey/WebAuthn في `app/auth/`.
- قاعدة البيانات في `app/db/`.
- المناهج في `app/curriculum/` و`app/curriculum_registry.py`.
- تقدم الطالب في `app/learning/`.
- الملفات في `app/files/`.
- الذكاء الاصطناعي في `app/agents/` وواجهات `agent_*`.
- الإشعارات، المدفوعات، والشهادات موجودة كطبقات مستقلة.
- Docker وRender وGitHub Actions موجودة للتشغيل والنشر.

## ما تم تثبيته الآن

أصبحت واجهة الأكاديمية قابلة للتثبيت كتطبيق PWA من المتصفح، مع Web App Manifest وService Worker وApp Shell caching. هذا لا يغيّر الـBackend ولا يجعل Telegram شرطًا للتشغيل.

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

ثم افتح `http://127.0.0.1:8000/web/`.

## اتجاه التطوير

1. تثبيت عقد API موحد للتطبيق.
2. تطوير تجربة الهاتف بالكامل فوق نفس الـAPI.
3. بناء Android/iOS فوق الـBackend نفسه.
4. ربط المعلم الذكي مباشرة بشاشات الدروس.
5. استكمال إدارة الجامعات والكليات والتخصصات والسنوات والفصول والمواد والدروس والملفات بدون حدود ثابتة.
6. استكمال الاشتراكات والوصول المدفوع وفق خطة الأكاديمية.
7. اختبارات وأمن ومراقبة قبل الإطلاق العام.

## قاعدة مهمة

لا نعيد المشروع إلى بنية Bot. أي قناة مستقبلية مثل Telegram تستخدم خدمات الـBackend نفسها، بينما التطبيق هو المنتج الأساسي.
