# TOFAN AI 2026

مساعد تعليمي ذكي على Telegram يستقبل ملفات الدروس، يستخرج النص منها، يشرح المحتوى باستخدام Google Gemini، وينشئ اختبارات فردية وجماعية متكررة.

## المزايا

- استقبال PDF وDOCX وTXT من Telegram.
- استخراج النص وتنظيفه وتقسيمه إلى أجزاء.
- حفظ الدروس ونتائج الاختبارات في SQLite.
- تحليل الدروس باستخدام Google Gemini.
- شرح منظم للدرس وأهم المفاهيم والنقاط.
- مكتبة دروس، وكل درس له أزرار مستقلة.
- اختبار جديد وإعادة الاختبار من نفس الدرس.
- اختبار جماعي داخل المجموعات والقنوات عبر Inline Keyboard.
- مشاركة نفس الاختبار بين المشاركين مع نتيجة مستقلة لكل طالب.
- لوحة متصدرين للاختبارات الجماعية.
- إنشاء MCQ وTrue/False وShort Answer للاختبارات الفردية.
- الاختبارات الجماعية تستخدم الأسئلة ذات الخيارات حتى تكون الإجابة بالضغط على الأزرار.
- تصحيح تلقائي وحساب النسبة وشرح الأخطاء.
- حفظ تقدم الطالب وإحصاءات النتائج.
- إعداد عدد الأسئلة ومستوى الصعوبة.
- بنية Modular قابلة لإضافة صيغ وخدمات أخرى لاحقًا.

## المتطلبات

- Python 3.11 أو أحدث.
- Telegram Bot Token من BotFather.
- Gemini API key من Google AI Studio.

## التثبيت

```bash
git clone https://github.com/781991937/TOFAN-AI-2026.git
cd TOFAN-AI-2026
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

في Windows:

```powershell
.venv\Scripts\activate
```

## إعداد البيئة

انسخ `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

ثم ضع القيم الخاصة بك:

```env
TELEGRAM_BOT_TOKEN=ضع_توكن_البوت_هنا
GEMINI_API_KEY=ضع_مفتاح_Gemini_هنا
GEMINI_MODEL=gemini-2.5-flash
MAX_FILE_SIZE_MB=20
```

**لا ترفع `.env` إلى GitHub.** وهو مستبعد بالفعل من `.gitignore`.

## تشغيل البوت

```bash
python -m app.bot.main
```

## الاستخدام الفردي

1. افتح البوت واضغط `/start`.
2. أرسل PDF أو DOCX أو TXT.
3. يستخرج البوت النص ويشرحه باستخدام Gemini.
4. تظهر أزرار: شرح الدرس، اختبار جديد، إعادة الاختبار، واختبار جماعي.
5. من `/lessons` تظهر مكتبة الدروس، ويمكن فتح أي درس وتشغيل الاختبار منه عدة مرات.

## الاختبار الجماعي

1. أضف البوت إلى المجموعة أو القناة.
2. في المجموعة استخدم `/lessons` لعرض دروسك ثم اختر الدرس واضغط `👥 اختبار جماعي`.
3. سيُنشر في المجموعة اختبار مشترك مع زر `🚀 انضم للاختبار الجماعي`.
4. كل مشارك يضغط الزر يحصل على محاولة مستقلة لنفس الأسئلة.
5. تظهر النتيجة لكل مشارك وتُحفظ في SQLite.
6. زر `🏆 لوحة المتصدرين` يعرض ترتيب المشاركين.
7. بعد الانتهاء يمكن استخدام `🔁 إعادة الاختبار` أو بدء اختبار جماعي جديد.

في القنوات، يجب أن يكون البوت قادرًا على نشر الرسائل ومعالجة منشورات القناة. يمكن نشر ملف درس في القناة، وسيتم تحليل الملف وإرفاق أزرار الشرح والاختبارات به.

**ملاحظة للمجموعات:** إذا أردت أن يستقبل البوت الملفات والرسائل العادية داخل المجموعة، عطّل Privacy Mode للبوت من BotFather (`/setprivacy`) أو اجعل البوت مسؤولًا حسب الحاجة.

## الأوامر

- `/start` — تشغيل البوت.
- `/help` — عرض المساعدة.
- `/lessons` — مكتبة الدروس.
- `/quiz` — اختبار آخر درس.
- `/summary` — شرح آخر درس.
- `/profile` — تقدم الطالب وإحصاءاته.

## التصميم البرمجي

- `file_extractor.py`: مسؤول عن PDF/DOCX/TXT والتنظيف والتقسيم.
- `ai_service.py`: مسؤول عن Google Gemini وتحليل المحتوى وتوليد الأسئلة.
- `quiz_generator.py`: طبقة مستقلة لإنشاء الاختبارات وتخزينها بصيغة JSON.
- `database/db.py`: طبقة SQLite للمستخدمين والدروس والاختبارات والنتائج ولوحة المتصدرين.
- `bot/handlers.py`: أوامر Telegram ومعالجة الملفات ومكتبة الدروس والاختبارات الفردية والجماعية.
- `bot/keyboards.py`: جميع أزرار Telegram وواجهات الدروس والاختبارات.
- `config_gemini.py`: إعدادات متغيرات البيئة الخاصة بـ Telegram وGemini.

## ملاحظات

- يتم حفظ النص الكامل المستخرج من الملف في قاعدة البيانات، بينما تُقسّم نسخة المعالجة إلى أجزاء عند إرسالها إلى Gemini.
- النسخة الحالية تستخدم polling.
- تخزين SQLite والملفات على Render Free محلي ومؤقت؛ للإنتاج طويل الأجل يفضّل لاحقًا استخدام قاعدة بيانات وخزنة ملفات خارجية.
